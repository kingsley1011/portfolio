# Kingsley Portfolio

A personal portfolio website for Kingsley, built with HTML, CSS, and JavaScript. It presents profile, skills, services, experience, and contact information in a single-page layout.

## Features

- Responsive navigation and section links
- Light and dark theme toggle
- Scroll-to-top control and scroll animations
- Service detail modals
- Clickable phone and email contact links

## Run Locally

No build tools or package installation are required. Open `index.html` in a web browser, or use a local development server such as the VS Code Live Server extension.

The site loads Google Fonts, Font Awesome, and ScrollReveal from external CDNs, so an internet connection is needed for those resources.
